# Demo video

The product walkthrough lives here as `lexora-demo.mp4` (local only).

**Do not commit the MP4 to GitHub** — it is ~500MB+ and exceeds GitHub’s file size limit. It is listed in `.gitignore`.

## Publish for Upwork / GitHub README

1. Upload `lexora-demo.mp4` to **YouTube** (unlisted), **Google Drive** (anyone with link), or **Loom**.
2. Paste that URL into the main project `README.md` under **Demo** (replace the placeholder link).
3. Keep this local file for editing / re-export.

Ideal length for clients: **60–90 seconds**, captions on, 1080p.
